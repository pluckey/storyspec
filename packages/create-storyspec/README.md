# create-storyspec

Scaffolds a [storyspec](https://github.com/pluckey/storyspec) app: story-first, spec-driven development on clean architecture with ports and adapters.

```bash
npm create storyspec@latest my-app                    # with the example notes API
npm create storyspec@latest my-app -- --no-example    # structure, tooling and one draft story
npm create storyspec@latest my-app -- --no-install    # skip npm install
```
